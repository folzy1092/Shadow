# Спецификация: пакет фич Shadow (2026-10-01)

Выбрано пользователем: проверка обновлений в настройках Shadow, №5 замок на
чаты, №9 скрытие рекламы, №10 чистый интерфейс, №14 шаблоны ответов,
№16 локальная расшифровка голосовых.

Общие правила (см. `docs/SHADOW_AGENT_MAP.md`):
- новые поля `AyuGramSettings` объявляются со значением по умолчанию,
  читаются в `init(from:)` (`decodeIfPresent`) и пишутся в `encode(to:)`;
- булевы поля добавляются в экспорт/импорт (`ShadowSettingsDocument` +
  `ShadowSettingsTransfer`) и в поиск настроек;
- в UI видимого аккаунта настройки читаются через `currentAyuGramSettings(accountId:)`
  или реактивно `ayuGramSettings(postbox:)`;
- новые экраны настроек — отдельные файлы `SettingsUI/Sources/Shadow*.swift`.

## 1. Чистый интерфейс (№10) и реклама (№9)

Четыре независимых переключателя в **Shadow → Кастомизация → Чаты**
(по умолчанию выключены; отдельного экрана нет):

| Поле | Переключатель | Что делает |
|---|---|---|
| `hideStoriesBar` | Скрыть истории | Лента историй над списком чатов не показывается (и в архиве). Сами истории доступны из профилей. |
| `hideGiftButton` | Скрыть кнопку подарка | Кнопка подарка в поле ввода (рядом со скрепкой) не показывается. |
| `hidePremiumBadges` | Скрыть значки Premium | Звёздочка Premium и эмодзи-статус рядом с именем не рисуются: список чатов, шапка чата, профиль, списки контактов/участников, имя автора в группе. Значки верификации, scam/fake и значки Shadow остаются. |
| `hideSponsoredMessages` | Скрыть рекламу в каналах | Спонсорские сообщения в каналах не загружаются и не показываются (контекст рекламы для чата не создаётся). Применяется при следующем открытии канала. |

Реализация:
- истории: в `ChatListController` подписка на истории объединяется с
  настройкой; при `hideStoriesBar` подставляется пустой
  `EngineStorySubscriptions` → `shouldDisplayStoriesInChatListHeader` = false;
- подарок: в `ChatInterfaceInputContexts` условие `showPremiumGift` дополнительно
  требует `!hideGiftButton`;
- Premium: на каждом месте отрисовки ветки `peer.emojiStatus` / `peer.isPremium`
  пропускаются при `hidePremiumBadges`;
- реклама: в `ChatControllerNode` `adMessagesContext` не создаётся при
  `hideSponsoredMessages`.

Риск: правила Telegram для сторонних клиентов требуют показывать рекламу в
каналах. Переключатель выключен по умолчанию.

## 2. Шаблоны быстрых ответов (№14)

- Поле `quickReplyTemplates: [String]` (до 50 шаблонов, каждый до 4096 символов).
  В экспорт настроек не входит (экспорт поддерживает только bool/int/короткий текст).
- Экран **«Шаблоны ответов»** в настройках Shadow: список шаблонов,
  «Добавить шаблон» (ввод текста), удаление и изменение по нажатию на шаблон.
- В поле ввода чата, когда поле пустое и шаблоны есть, появляется кнопка
  шаблонов (иконка «текст в пузыре», рядом с другими кнопками поля).
  Нажатие → меню-список шаблонов (первые ~40 символов каждого) →
  выбранный текст вставляется в поле ввода (не отправляется сам).
- Реализация: новый `ChatTextInputAccessoryItem.shadowTemplates`
  (+ ключ, иконка, ширина, обработчик), колбэк
  `ChatPanelInterfaceInteraction.openShadowQuickReplyTemplates`.

## 3. Расшифровка голосовых на устройстве (№16)

- Поле `localVoiceTranscription: Bool = true`, переключатель в
  «Кастомизация → Медиа».
- Когда включено и у аккаунта нет Premium: кнопка расшифровки показывается
  у всех голосовых сообщений (в т.ч. в секретных чатах), нажатие
  расшифровывает аудио на устройстве (`SFSpeechRecognizer`,
  `requiresOnDeviceRecognition`) через уже существующий в Telegram путь
  `transcribeAudio(path:appLocale:)` + `storeLocallyTranscribedAudio`.
  Аудио на сервер Telegram не отправляется.
- Язык распознавания = язык интерфейса Telegram. Кружки (видеосообщения)
  локально не расшифровываются — для них остаётся обычное поведение.
- При Premium используется серверная расшифровка, как раньше.
- Первое использование показывает системный запрос доступа к распознаванию речи.

## 4. Проверка обновлений (в настройках Shadow)

- CI (`build.yml`): после успешной сборки `master` создаётся GitHub Release
  `build-<номер сборки>` с IPA (`gh release create`, права `contents: write`).
- Экран **«Обновления»** в настройках Shadow:
  «Установлена: Shadow 12.9.2 (сборка N)», при открытии запрос
  `https://api.github.com/repos/folzy1092/Shadow/releases/latest`,
  статус «Актуальная версия» / «Доступна сборка M» / «Не удалось проверить».
  Кнопка «Открыть страницу загрузки» → страница релиза в Safari.
  Кнопка «Проверить снова».
- Фоновой проверки и всплывающих окон нет.

## 5. Замок на чаты (№5)

Хранилище — `ShadowChatLock` (TelegramCore/AyuGram, только Foundation +
CommonCrypto, UserDefaults устройства):
- заблокированные чаты — отдельно для каждого аккаунта (по id аккаунта);
- пароль — один на устройство, хранится как PBKDF2-SHA256 (соль + 100 000
  итераций), сам пароль не хранится;
- отложенный сброс — время запроса сброса.

Поведение:
- **Защитить чат / снять защиту**: пункт сразу после «Закрепить» в меню чата
  (долгое нажатие в списке чатов), а также кнопка 🔒 справа вверху в режиме
  «Изменить», когда выбраны чаты (все выбранные защищены → снять, иначе
  защитить). Блокировка первого чата без заданного пароля сначала просит
  придумать пароль (ввести дважды, минимум 4 символа). Снятие замка требует
  Face ID / Touch ID или пароль.
- **Открытие чата**: экран чата закрывается непрозрачной шторкой с замком
  (шапка с именем и кнопка «назад» видны). Сразу запрашивается Face ID;
  при отмене/неудаче — кнопка «Ввести пароль». После успеха чат
  разблокирован до ухода приложения в фон. Это работает для любого входа в
  чат: список, поиск, уведомление, ссылка, предпросмотр долгим нажатием
  (в предпросмотре шторка без запроса Face ID).
- **Список чатов**: имя видно, текст последнего сообщения показывается
  спойлером Telegram, миниатюры медиа не показываются.
- **Настройки Shadow → «Замки чатов»**: список заблокированных чатов
  (снять замок — после Face ID/пароля), «Сменить пароль» (нужен старый
  пароль или Face ID).
- **Сброс**: «Сбросить все замки» →
  - с паролем — сразу;
  - «Не помню пароль» — запускается таймер на 1 час; через час кнопка
    «Сбросить сейчас» снимает все замки и удаляет пароль. Любая успешная
    разблокировка чата (Face ID или пароль) за этот час отменяет сброс.
- Ограничения: push-уведомления показывает iOS — текст в них скрывается
  только штатной настройкой Telegram «Показывать текст» для чата.
  Черновик в списке чатов не скрывается.
