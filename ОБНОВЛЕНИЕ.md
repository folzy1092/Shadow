# Как обновить Shadow на свежий Telegram

Инструкция для случая «прошло полгода, я не помню код».

## Одна команда

Из корня репозитория (Git Bash на Windows, Terminal на маке):

```bash
bash tools/shadow-update.sh
```

Скрипт сам:
1. скачает свежие версии Telegram,
2. найдёт самую новую,
3. создаст ветку `update-release-X.Y.Z` и вольёт в неё Telegram,
4. если конфликтов нет — запушит ветку.

## Дальше — один из двух вариантов

### Вариант А: конфликтов не было

Скрипт напишет, что смержилось чисто, и запушит ветку. Останется влить её
в основную, чтобы CI собрал IPA:

```bash
git checkout master
git merge update-release-X.Y.Z
git push ghostgram master
```

Готово. Сборка придёт в Telegram/Discord.

### Вариант Б: были конфликты

Так бывает: Telegram переписал те же файлы, где форк делал свои правки.
Форк меняет ~88 файлов апстрима, поэтому это скорее норма, чем ЧП.

Скрипт создаст файл **`UPDATE_REPORT.md`**. В нём по каждому конфликтному
файлу показано, что именно форк там добавлял.

**Если сам не разбираешься:** открой `UPDATE_REPORT.md`, скопируй целиком
и отдай любому ИИ (хоть бесплатному) со словами:

> помоги разрешить конфликты мержа в форке Telegram-iOS, вот что мой форк
> менял в этих файлах

Когда конфликты разрулены:

```bash
git add .
git commit
git checkout master
git merge update-release-X.Y.Z
git push ghostgram master
```

**Если решил забить и откатиться** — ничего не сломается:

```bash
git merge --abort
git checkout master
git branch -D update-release-X.Y.Z
```

Форк останется на старой версии Telegram и продолжит работать как работал.

## Что вообще форк меняет

Полный список — в **`FORK_CHANGES.md`** (обновляется автоматически при
каждом запуске скрипта). Пересобрать вручную:

```bash
bash tools/shadow-update.sh --inventory
```

Там два раздела:
- **свои файлы форка** (45 шт.) — их в Telegram нет, они не конфликтуют
  никогда, трогать не нужно;
- **правки в файлах апстрима** (88 шт.) — вот здесь и бывают конфликты,
  отсортированы по объёму правок.

Посмотреть, что форк наменял в конкретном файле:

```bash
git diff release-12.9.2 HEAD -- путь/к/файлу.swift
```

(`release-12.9.2` — версия Telegram, на которой форк стоит сейчас;
актуальную смотри в шапке `FORK_CHANGES.md`.)

## Полезные флаги

```bash
bash tools/shadow-update.sh --version release-13.0   # на конкретную версию
bash tools/shadow-update.sh --no-push                # не пушить автоматом
bash tools/shadow-update.sh --inventory              # только обновить FORK_CHANGES.md
```

## Чего скрипт НЕ делает

- **Не решает конфликты сам.** Свести правки форка с переписанным кодом
  Telegram автоматически нельзя — тут нужен человек или ИИ.
- **Не собирает IPA локально.** Сборка только на macOS через CI (GitHub
  Actions собирает сам при пуше в `master`).
- **Не проверяет, что приложение работает.** Собралось ≠ работает; фичи
  форка после обновления стоит прощёлкать руками.
